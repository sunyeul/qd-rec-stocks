# QD-Rec 기반 미국 주식 아이디어 발굴: 설계

> 현재 설계만 적는다. 바뀐 과정은 git 기록에 있다.

## 목적과 범위

Sakana AI의 QD-Rec(arXiv 2610.23470)을 미국 주식에 적용해, "종목 + 투자논리" 아카이브를 만들고 그 결과를 블로그 글 한 편으로 공개한다. 방법론을 증명하거나 반박하는 것이 아니라, 싸고 빠르게 다음을 보여준다.

| | 질문 | 보여줄 것 |
| --- | --- | --- |
| A | 무엇을, 왜 추천했나 | 포트폴리오 종목별 투자논리·촉매·반증 조건·반론. 당시 정보만 썼다는 근거 |
| B | 실제로 어땠나 | 종목별·포트폴리오 1·3개월 수익. 기준은 SPY, RSP(균등 비중 S&P 500), QQQ, 유니버스 균등 비중 |
| C | 돌려볼 만한가 | 실행당 비용, 시간, 숫자 검증 실패율 |
| D | 쓸모가 있어 보이나 | 점수와 실제 초과수익의 순위 상관(IC) |
| E | QD-Rec다운가 | 같은 비용의 Novelty(무작위 선택, 예시 없음)와 비교한 탐색 범위·아이디어 수·다양성·품질 추이 |

자동매매나 매매 권유가 아니라 검토 후보를 만드는 실험이다.

## 개념 매핑

| QD-Rec | 이 프로젝트 |
| --- | --- |
| 후보(item) | 스냅샷 t의 S&P 500 종목. 숫자·사업 요약·최근 30일 뉴스 요약이 붙은 "종목 카드" |
| 프로필 | 중립 투자자: 3~12개월, S&P 500 초과, 미국 대형주, 매수만 |
| 가설 | 투자논리: thesis, evidence, catalyst, risks, falsifier, horizon |
| 품질 | 10 × P(이 종목이 3개월간 S&P 500을 이긴다), 심사자 Jev의 확률 |
| 아카이브 → 결과 | 종목별 최고 점수 아이디어 상위 20, 섹터당 3, 동일 비중 포트폴리오 |

## 데이터 (`ingest/`)

과거 날짜 t마다 "t일 뉴욕 장 마감(16:00)까지 알 수 있던 것"만으로 스냅샷을 다시 만든다(`ingest/backfill.py`, 저장은 `data/backtest500/`).

| 소스 | 방법 | 시점 규칙 |
| --- | --- | --- |
| 유니버스 | Wikipedia "List of S&P 500 companies"의 t 직전 판 | 당시 구성(생존 편향 없음) |
| 가격 | yfinance 일별 종가 → 수익률·모멘텀·변동성·거래대금 | t 이전 종가만 |
| 재무 | yfinance 연간 재무제표에서 PER·PBR·성장률·이익률·ROE·부채비율·배당률·베타를 재계산 | 회계연도 종료 + 60일 이후만 |
| 뉴스 | Google News RSS 검색(기간 지정): 제목·매체·날짜 | t 전날까지(RSS 시각을 믿을 수 없어 t 당일 제외) |

누출 방지: 카드를 만드는 코드는 `ingest.reader`로만 읽는다. t 이후 가격은 `evaluation/`에서만 읽고, 수익률은 t 종가부터 잰다.

## 종목 카드 (`apps/stocks/items.py`, `summaries.py`)

- 숫자(수익률, 변동성, 밸류에이션, 성장·수익성), 사업 요약 3문장, 최근 30일 뉴스 요약("사실"과 "해석이 갈리는 점"). 영어, 약 450토큰(상한 1,500).
- 뉴스 요약은 LLM이 종목·날짜당 한 번 만들고 캐시한다. 원문에 없는 숫자가 들어간 문장은 버린다.
- 익명 모드(`ANONYMIZE=1`): `C-###` ID, 시가총액 구간, 회사명·티커 가림.

## 생성과 심사 (`proposer.py`, `verifier.py`, `evaluation.py`, `qd_rec.py`)

1. **제안:** 카드(와 QD-Rec이면 아카이브의 기존 논리 3개)를 보고 JSON 투자논리를 쓴다. 정형화된 첫 문장을 금지하고 종목 고유의 수익 원천으로 시작하게 한다.
2. **숫자 검증:** thesis·evidence·catalyst·risks의 숫자가 카드나 프로필에 없으면(반올림·보유 기간 표현은 허용) 0점. 루프에서는 버리고, 시드에서는 예비 종목으로 바꾼다.
3. **반론:** 공매도자 입장의 가장 강한 반론을 쓴다(TradingAgents의 강세·약세 토론에서 착안).
4. **심사(Jev):** 카드·논리·반론을 보고 "3개월간 S&P 500을 이길까"의 확률을 낸다. 점수 = 10 × 확률. 근거 일치 등 기준별 점수는 진단용이며, 근거가 없다고 판정되면 0점.
5. **새로움 판정과 맞대결(Jev):** 아카이브 임베딩(종목명·섹터 한 줄 + 논리)으로 가장 가까운 기존 논리 3개와 비교해, 새로우면 추가하고 아니면 블라인드 맞대결로 하나만 남긴다.
6. **밴딧:** 카드 임베딩으로 다음에 볼 종목을 고른다(QD-Rec). Novelty는 무작위로 고르고 예시 없이 쓴다.

## 모델과 학습 마감일

모든 모델의 학습 마감일보다 뒤의 스냅샷만 쓴다.

| 역할 | 모델 | 학습 마감일 |
| --- | --- | --- |
| 제안자 | `google/gemini-3.5-flash-lite` (추론 강도 low) | 2026-03 (Google 모델 카드) |
| 반론, 뉴스 요약 | `google/gemini-2.5-flash-lite` | 2025-01-31 |
| 심사자 | `typesafe/jev-1.14` (OpenRouter Decisions API) | 공개 안 됨. 2026년 3~9월 실제 주가 변동 60쌍을 참·거짓으로 구분하지 못함(AUC 0.50, 2024년은 0.57) |
| 임베딩 | `openai/text-embedding-3-small`, 512차원 | 해당 없음 |

논문은 제안자 claude-sonnet-5, 심사자 gpt-5.6-terra를 썼다. 이 PoC는 예산 때문에 저가 모델을 쓴다.

## 실행 (`scripts/backtest.py`)

```
uv run python -m scripts.backtest --step 1     # 다음 날짜 하나, 리포트 후 멈춤
```

- 날짜: 2026-04-30, 05-29, 06-30, 07-31, 08-31, 09-22 (월말, 1개월 채점이 가능한 마지막 날까지)
- 변형: QD-Rec과 Novelty 각 300회. 익명 QD-Rec은 05-29, 08-31에 추가
- 비용: 평가 1회 약 $0.002, 날짜당 뉴스 요약 약 $0.15. 예산 확인은 키 한도와 계정 잔액 중 작은 쪽
- 리포트: `reports/backtest500.md` (A~E 순서)

## 결과 (2026-04-30만 실행하고 멈춤)

- **B:** 1개월 SPY 대비 QD-Rec −5.9%p, Novelty −5.7%p, 균등 비중 −3.3%p, RSP −2.7%p, QQQ +5.7%p. 대형 기술주 장세였고, 섹터당 3종목 제한으로 기술주가 적었다. 3개월은 모두 SPY 수준(+0.5%p 안팎).
- **C:** QD-Rec $0.74(카드·시드 포함), 4.2분. Novelty $0.44, 5.8분. 숫자 검증 실패 5~6%.
- **D:** IC(1개월) QD-Rec +0.01, Novelty −0.05, 표준오차 약 0.07. 점수와 수익의 관계는 보이지 않았다.
- **E:** 같은 300회에서 QD-Rec은 300종목을 탐색했고(Novelty 223), 아이디어 206개(165)를 남겼고, 수익 원천이 더 고르게 퍼졌다(엔트로피 0.93 대 0.87). 상위 20개 품질은 둘 다 실행 내내 올랐다.

## 한계

- 날짜 하나라 수익은 사례일 뿐이고, 시장 국면(기술주 장세)의 영향을 걸러낼 수 없다.
- 심사 점수가 좁게 몰린다(포트폴리오 4.4~5.1). Jev가 대부분 0.45 안팎의 확률을 낸다.
- 종목당 아이디어가 1개다. 300회로 497종목을 보면 밴딧이 안 본 종목을 우선해 재방문이 거의 없다.
- 규모가 논문(실행당 1,000회)보다 작다.
- Jev의 학습 마감일은 공개되지 않았다(간이 확인만 함). 과거 뉴스는 오늘의 검색 순위가 고른 제목이고, 사업 요약은 오늘 받은 설명이다. 시가총액은 오늘의 주식 수로 계산했다. 나중에 사라진 티커 몇 개는 데이터가 없어 빠졌다.
- 진화 연산자 꼬리표(변형·조합·탐색)는 모델의 자기 보고라 참고만 한다.
